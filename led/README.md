# LED連携（Phase 5 用）

LED制御はクイズ本体から分離します。現時点では基板と接続方式が未決定のため、実装は置いていません。

将来は各回答PCで小さなローカル常駐プログラム（LEDエージェント）を動かし、player画面が不正解を受け取ったときだけ `http://127.0.0.1:<専用ポート>/effects/incorrect` のようなローカルAPIを呼ぶ方式を推奨します。

- LEDエージェントが停止していても、回答・判定・画面表示は継続する
- USB通信と機種依存処理はこのディレクトリ内へ閉じ込める
- ブラウザからUSBを直接扱わないため、毎回の権限確認を避けられる
- API呼び出しは短いタイムアウトで失敗を無視する

実際の基板、USB上の認識方式（シリアル/HID等）、制御コマンドが決まってから実装します。
