# けやき祭 ローカルLANクイズシステム

## 起動方法

1. 管理PCと回答PC3台をLANケーブルでLANスイッチへ接続する。
2. 各PCのIPv4アドレスを手動設定する。例として、管理PCを`192.168.10.10`、PC1を`192.168.10.11`、PC2を`192.168.10.12`、PC3を`192.168.10.13`、サブネットマスクを全台`255.255.255.0`にする。インターネットへ接続しないからゲートウェイとDNSは空欄でよい。
3. 管理PCでターミナルを開き、プロジェクトへ移動する。
4. 初回だけ、必要なパッケージをインストールする。この作業にはインターネット接続が必要だが、完了後はオフラインで使用できる。
   ```bash
   npm install
   ```
5. `.env`を開き、各問題の正解を設定する。問題文とPCへの割り当てを変える場合は`server/questions.js`を編集する。
6. 管理PCでサーバーを起動する。
   ```bash
   npm start
   ```
7. Macから「Nodeが外部からの接続を受け入れることを許可しますか」と表示された場合は許可する。
8. 管理PCで`http://localhost:3000/admin`を開く。
9. PC1で`http://192.168.10.10:3000/player?id=pc1`、PC2で`http://192.168.10.10:3000/player?id=pc2`、PC3で`http://192.168.10.10:3000/player?id=pc3`を開く。管理PCのIPアドレスを別の値にした場合は、URLの`192.168.10.10`も変更する。
10. 終了するときは、サーバーを起動したターミナルで`Control + C`を押す。問題や正解を変更した場合も、一度停止して`npm start`で再起動する。

## 実装できてる機能

- インターネットを使わず、ローカルLAN内で動作
- `pc1`、`pc2`、`pc3`の端末識別とlocalStorageへの保存
- `pc1→問題1`、`pc2→問題2`、`pc3→問題3`の個別出題
- 回答の直接入力と管理PCへの送信
- `.env`に保存した正解によるサーバー側判定
- 空白、全角・半角、英字の大文字・小文字、複数の正答表記への対応
- 正解・不正解を3秒表示した後、同じ問題へ自動復帰
- 回答PCの接続状態、回答状態、最終回答、最終判定の管理
- Socket.IOによる管理画面へのリアルタイム通知
- 正解データを回答PCへ送信しない構成

## 2台構成の運用方法

### 管理PC
1. 管理PCでこのプロジェクトを起動する。
   ```bash
   npm install
   npm start
   ```
2. ブラウザで`http://localhost:3000/admin`を開く。

### Player PC
1. Player PCでもこのプロジェクトのコードを置く。
2. そのPCでブラウザから`http://localhost:3000/player?id=pc1`などを開く。
3. そのPCのブラウザでは `navigator.serial.requestPort()` によるUSB接続を使う。
4. そのPCで別途、ローカルのシリアル用アプリを起動する。
   ```bash
   npm install
   npm run player-agent
   ```
5. 管理PC側の `.env` に `PLAYER_AGENT_URLS` を設定して、Player PCのローカルエージェントへLAN経由で文字列を送れるようにする。
   ```env
   PLAYER_AGENT_URLS=pc1=http://192.168.10.11:3100,pc2=http://192.168.10.12:3100,pc3=http://192.168.10.13:3100
   ```

### Player PC側のエージェント設定例
```env
PLAYER_AGENT_PORT=3100
SERIAL_PORT=/dev/ttyUSB0
SERIAL_BAUD_RATE=115200
```
